# Pasindu Piyumal Portfolio

This is a responsive portfolio website built using HTML5, CSS3, and vanilla JavaScript only.

## Files
- `index.html` — page structure and portfolio content
- `css/style.css` — complete design system, layout, responsiveness and animations
- `js/script.js` — navigation, filtering, modal, testimonials, form validation and scroll effects
- `images/profile.svg` — main profile artwork
- `images/project1.svg` to `images/project6.svg` — portfolio placeholder art files

## Open the site
Open `index.html` directly in any modern browser.

## Customize
- Update name, contact information, skills and project details in `index.html`.
- Replace `images/profile.jpg` with your preferred portrait.
- Replace project images in `images/project1.jpg` to `images/project6.jpg` with your own work.
- The form is frontend-only and validates but does not send to a backend server.
